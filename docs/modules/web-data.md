# Модуль web-data — сторінки керування даними

Мета: диспетчер веде довідники, календар, навантаження, облік годин і імпорт файлів у SPA, без SQL і без
ручного редагування Excel. Код — `web/src/pages/admin/{catalog/*,CalendarPage,LoadPage,AccountingPage,ImportPage}.tsx`,
компоненти `web/src/components/{catalog,calendar,load,accounting,import}/`, хуки `web/src/api/{catalog,calendar,load,accounting,import}.ts`,
моки `web/src/mocks/handlers/` з тими ж іменами.

## Маршрути

| Маршрут | Що робить |
|---|---|
| `/admin/catalog/groups` | Групи й підгрупи: курс, спеціальність, зміна, куратор, домашня аудиторія |
| `/admin/catalog/teachers` | Викладачі, псевдоніми з таблиць («Хорченко О.»), дисципліни, які веде (компетенції) |
| `/admin/catalog/rooms` | Аудиторії: тип, місткість, корпус |
| `/admin/catalog/disciplines` | Дисципліни, псевдоніми, колір лінії з попереднім переглядом клітинки в обох темах |
| `/admin/catalog/structure?tab=` | Відділення, спеціальності, циклові комісії, корпуси |
| `/admin/calendar?tab=` | Семестри й активація, тижні чисельник/знаменник з ручним перемиканням, періоди, профілі дзвінків |
| `/admin/load` | Навантаження за семестром і групою, тижневий візерунок «1 + ½», «Вивести з розкладу» |
| `/admin/accounting?tab=` | План / факт / прогноз за групою, дата вичитки, пропозиції в заміни; статистика викладачів за місяць |
| `/admin/import?job=` | Завантаження файлу, список завдань, звіт, рішення щодо невідомих назв, чернетка, застосування |

## Рішення

- **Стан таблиці в адресі.** `useTableUrlState` тримає пошук, сторінку, сортування й фільтри в query, тож
  посиланням можна поділитися, а «Назад» повертає ту саму вибірку. Розмір сторінки — 25 (`CATALOG_PAGE_SIZE`).
- **Форми: zod + react-hook-form, помилки сервера на поля.** `applyServerErrors` розкладає `errors[]` ProblemDetail
  по полях форми; 409 (дублікат, «дані змінилися») показується над полями в `FormAlert`. Закриття форми зі
  змінами питає підтвердження; фокус при відкритті — у перше поле.
- **Видалення.** `DeleteDialog` питає підтвердження, а на 409 «використовується» пояснює причину словами
  бекенду й пропонує «Позначити неактивною» замість видалення.
- **Оптимістичне перемикання парності тижня** з відкатом при помилці і тостом «Скасувати».
  Місяць над тижнем — за його четвергом (як ISO-тиждень).
- **Імпорт опитує сервер, поки завдання зайняте** (`UPLOADED/PARSING/APPLYING`). Після застосування
  інвалідуються `qk.admin.all`, список завдань і витрати ШІ, але не ключ самого завдання: інвалідація власного
  ключа з `queryFn` скасовувала запит і зациклювала опитування.
- **Тип файлу визначається за розширенням** (`components/import/detect.ts`), користувач може змінити його
  вручну. Для програми дисципліни і навчального плану треба вибрати групи — вони йдуть в `options.groupIds`.
- **Схожість у звіті** — число 0..1, у таблиці показується відсотком.
- **Пропозиції обліку ведуть у заміни:** `/admin/changes?group=<id>&discipline=<id>&suggest=<kind>&date=<iso>`.
  Сторінка замін цих параметрів поки може не читати — це контракт для неї.
- **Версії розкладу для «Вивести з розкладу».** Хук `useTimetableVersions` бере `qk.admin.timetable.versions`.
  Запасний мок `GET /admin/timetable/versions` у `handlers/load.ts` вмикається, лише якщо в тій самій теці
  немає `timetable.ts` чи `generation.ts` (перевірка через `import.meta.glob`), щоб не перекривати мок агента розкладу.
- **Спільні файли не змінювались:** роутер, лейаути, `components/ui`, `components/schedule`, `api/types.ts`,
  `queryKeys`. Ключі областей складаються з наявних `qk.*` із суфіксами.

## Дані моків

- Каталог — фікстури з `seed/schedule-2025-26.xlsx`; псевдоніми «Хорченко О.», «ХарченкоГ.», «Вернигорв»,
  «Укр.мова.», «Фк» тощо. Компетенції викладачів зібрано з шаблону розкладу.
- Навантаження 4КІ1 виведене з шаблону (обидва тижні = 1, лише чисельник чи знаменник = ½). НДЕКСМ (40 год)
  взято з реальної програми; СТП (48) і ОПЦЗ (20) — демонстраційні.
- Облік годин рахується як `HoursLedger` у ядрі (допуск 2 год, репрезентативна підгрупа); заміни — розпорядження
  №35 і демонстраційні листопадові.
- Імпорт: чотири завдання (фото розпорядження №35 — готове; розклад з одруківками «Граболінська», «Герасменко»,
  «Інфом.», «Вс.спц.», обрізаним «Вс.» і виправленими кодами «ІКІ1», «1ТК 1», «4КИ1» — чекає рішень;
  програма ЕУІТП — готова; навчальний план — збій бюджету ШІ). Статус нового завдання просувається на кожному
  опитуванні, тож увесь шлях видно за кілька секунд.
- Стан живе до перезавантаження сторінки (так влаштовані сховища моків).

## Відомі прогалини

- Запрошення викладачів (вхід у систему) лише показуються в таблиці, надсилання не зроблене.
- Вікна змін (`/admin/shift-windows`) — лише читання.
- Прогрес застосування імпорту невизначений (крутилка й секунди), бо API не віддає відсоток.
- Корпуси й циклові комісії в моках порожні — показано порожній стан з дією.
- Нативні поля дати й часу показують формат мови браузера (у headless Chrome — американський).
