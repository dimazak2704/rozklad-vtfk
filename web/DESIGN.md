# Design System: Розклад ВТФК

**Direction: «Повітря» з живим часом.** A calm personal calendar where only time moves. One sky-blue
signal marks "now"; the rest of the page stays quiet until the user hovers, taps or asks.

The owner's brief: stylish, beautiful, alive but calm; not overloaded with buttons, numbers and letters; the
user never wonders what to do; every page has an obvious way back; the theme follows the system.

This replaced the "трамвайний розклад на зупинці" direction (navy band, condensed type, route plates) in
round 8. Token values live in `src/styles/theme.css`; §15 says how the code maps to this document.

---

## 2. Principles (the rules everything else follows)

1. **Only time moves, and only "now" is blue.**
   - The accent marks the current moment, the selected thing, the single primary action and focus. Nothing else.
2. **One loud thing per screen.**
   - Home: the countdown.
   - Group page: the group code and the grid.
   - Admin «Заміни»: the decision in the options column.
   - Everything else is ink on canvas, with hairlines.
3. **Every state is shape and word first, colour second.**
   - A change is readable in greyscale: a word, a strike-through, a wash or an outline.
4. **Say it in a sentence, not in a number.**
   - "Далі перерва 20 хв, 5 пара о 13:30" replaces eight timestamps.
   - "Вирішено 3 з 7 пар" replaces a KPI tile row.
5. **Secondary things wait.**
   - Hover/focus cards, a single `⋯` menu and disclosures hold everything a person does not need in the first second.
6. **The theme follows the system.**
   - `preference: 'system'` is already the default in `src/stores/theme.ts`; keep it.
   - The manual override lives in the footer (public) or the user menu (cabinets), never in the header.

## 3. Colour

### 3.1 Token architecture (fixes the "islands go dark" bug)

**The bug:** the build currently emits
`--background-color-surface: var(--lightningcss-light,var(--grey-0)) var(--lightningcss-dark,var(--graphite-900))`
(checked in `web/dist/assets/index-*.css`).

**The cause:** Lightning CSS polyfills `light-dark()` with variables that resolve where the token is
*declared* (`:root`), not where it is *used*. A `data-theme="light"` island inside a dark page
therefore inherits dark values: the order sheet, the QR plate and the print sheet all go dark.

**New rule:** semantic tokens get **no `light-dark()`**. The values are declared once per theme, and
Tailwind utilities read them inline:

```css
/* theme.css: shape of the new file */
@custom-variant dark (&:where([data-theme='dark'], [data-theme='dark'] *));

:root, [data-theme='light'] {
  color-scheme: light;
  --c-canvas: oklch(98.5% 0.004 247);
  --c-surface: oklch(100% 0 0);
  /* …every role from the table in §3.2… */
}
[data-theme='dark'] {
  color-scheme: dark;
  --c-canvas: oklch(17.8% 0.012 256);
  --c-surface: oklch(21% 0.013 256);
  /* … */
}

@theme inline {
  --color-*: initial;
  --background-color-canvas: var(--c-canvas);
  --background-color-surface: var(--c-surface);
  --text-color-primary: var(--c-ink);
  /* …same role names the components already use… */
}
```

- The dark block comes after the light block, so `<html data-theme="dark">` wins over `:root`.
- `@theme inline` makes `bg-surface` compile to `background-color: var(--c-surface)`, so the value
  resolves on the island element itself.
- **Verify after the build:** `grep -c lightningcss dist/assets/index-*.css` should be `0` for colour
  tokens, and the `OrderSheet` stays light in dark mode.
- Check `@theme inline` against the current Tailwind 4 docs (Context7) before relying on it.
- **Keep the existing role names** (`canvas`, `surface`, `raised`, `sunken`, `hover`, `active`,
  `selected`, `accent`, `change`, `cancel`, `add`, `room`, `primary`, `secondary`, `muted`, `control`
  and so on). Then most components change colour without code edits.
- **Retire** the `shell*`, `on-shell*`, `plate` and `border-shell` roles (the navy band). Alias them
  to canvas, ink and separator for one commit, then delete their usages.
- **Add** these roles:
  - `today-wash` (the today column and the hero);
  - `now` (the now-line);
  - `track-past` and `track-future` (day track segments);
  - `change-mark`, `cancel-mark`, `add-mark` and `room-mark` (dots and strike lines);
  - `brand-sky` (the logo mark only).

### 3.4 Discipline colour rule

- **Keep the existing 5-line system unchanged:** `src/styles/lines.css`, `LINE_HUES = [115, 186, 290,
  320, 352]`, `assignLines` and the catalog swatches. Every hue is at least 30° from the state hues
  (27, 62–82, 150, 222) and from the accent (244–248), so this needs no data migration.
- **The colour appears only as an 8 px round dot** before the discipline title in these places:
  - week cells;
  - "4КІ1 сьогодні" rows;
  - the hover card;
  - admin timetable and load charts.

  It is **never** a fill, never text colour and never a side bar. Light dots are `56% 0.12 h`
  (≥ 4.5:1 on surface), dark dots `72% 0.09 h`.
- **Assignment per screen:**
  1. Feed `assignLines` the visible week's disciplines, sorted by number of pairs (descending).
  2. The 5 most frequent get hues; the rest get the neutral dot (`--fill-muted`).
  3. A colour stored in the catalog (`DisciplineRef.color`) wins through the existing nearest-line lookup.
- **Past pairs today** show the dot at 40 % opacity ("settling", §8.2).

## 4. Typography

**Two families, both OFL and self-hosted through Fontsource (variable, `wght` axis).**

| Family | Package | Import (in `src/main.tsx`) | CSS family | Weights used |
|---|---|---|---|---|
| **Manrope**: UI and text | `@fontsource-variable/manrope` 5.3.0 | `import '@fontsource-variable/manrope/wght.css'` | `'Manrope Variable'` | 450 body, 500–550 UI, 600–700 labels and titles |
| **Geologica**: display and figures | `@fontsource-variable/geologica` 5.3.0 | `import '@fontsource-variable/geologica/wght.css'` | `'Geologica Variable'` | 300 countdown numeral, 500 figures, 600 headings, group codes |

- **Subsets.** Both packages ship `cyrillic`, `cyrillic-ext`, `latin`, `latin-ext`, `greek` and
  `vietnamese` faces with `unicode-range`, so the browser downloads only what a page uses: in
  practice cyrillic plus latin.
  - Ukrainian і ї є and Ґ ґ (U+0490–0491) and № (U+2116) are in `cyrillic`.
  - The apostrophe ʼ (U+02BC) is in `latin`.
  - ₴ (U+20B4) is in `cyrillic-ext`.
  - The extra Geologica axes (CRSV, SHRP, slnt) are **not** loaded: use `wght.css`, not `full.css`.
- **Remove** `@fontsource/fira-sans` and `@fontsource/fira-sans-condensed`, and delete
  `--font-condensed`.
- **Tailwind tokens:**
  - `--font-sans: 'Manrope Variable', system-ui, 'Segoe UI', Roboto, sans-serif`
  - `--font-display: 'Geologica Variable', 'Manrope Variable', system-ui, sans-serif`
- **Figures.** A `.figures` utility (`font-family: var(--font-display); font-variant-numeric:
  tabular-nums; font-weight: 500`) goes on times, pair numbers, date numbers, counts and room numbers
  in columns.
  - Manrope's tabular "1" opens gaps in "11:11"; Geologica's tnum does not (checked by «Живий день»).
  - Times inside a running sentence stay in Manrope.
- **Glyph check before merging.** Render «4КІ1 4ОП1 1ІТ1 ґєїʼ 11:11 08:30» in Geologica 600 at 44 px
  and 15 px, in both themes. If І and 1 touch, set `letter-spacing: 0.01em` on group codes.

## 6. Motion

**Tokens (in `theme.css` and `motion.css`)**

| Token | Value | Use |
|---|---|---|
| `--duration-instant` | 100 ms | press feedback |
| `--duration-fast` | 160 ms | hover, colour, reveal of row actions |
| `--duration-base` | 200 ms | popover and menu in, digit roll, wash fade |
| `--duration-slow` | 280 ms | dialog and sheet in |
| `--duration-tick` | 1000 ms | now-line glide, current-pair fill (linear) |
| `--duration-live` | 1600 ms | live-dot halo (×2 only) |
| `--ease-out` | `cubic-bezier(0.22, 1, 0.36, 1)` | everything entering |
| `--ease-in` | `cubic-bezier(0.4, 0, 1, 1)` | exits (at 0.75× duration) |
| `--ease-in-out` | `cubic-bezier(0.4, 0, 0.2, 1)` | the theme swap view transition |

Animate only `transform` and `opacity`, plus `clip-path` for the strike line. Buttons press to
`scale(0.98)`. Popovers enter with fade, a 4 px rise and 0.98 → 1 scale. Nothing loops forever
except the spinner. This is the repo's existing rule; keep `--animate-live` at 2 iterations.

**Signature motions (the "alive" layer)**

1. **The now-line glides.**
   - Every minute (the existing `useNow`), the week-grid now-line and its pill move by `translateY`
     over 1 s linear.
   - In the day track, the current-segment fill grows with `scaleX` from the left.
2. **The countdown rolls.** When the minute changes, the old digits leave upward (opacity 1 → 0,
   −4 px) and the new ones enter from +4 px, over 200 ms `--ease-out`. Only the digits that changed move.
3. **A pair begins.** When the current pair changes:
   - the live dot plays its halo twice (`live-pulse`, 1.6 s);
   - the finished pair's dot fades to 40 % and its title fades to `secondary` over 280 ms ("settling").
4. **A change arrives live (SSE), once.**
   - The strike line draws across the old value: `clip-path: inset(0 100% 0 0) → inset(0)`, 200 ms.
   - Then the wash fades in over 200 ms and the state word slides 4 px.
   - No repeated pulses.
5. **The mark draws itself once** on the sign-in screen: stroke-dashoffset, 1.4 s `--ease-out`.
6. **A new row arrives, once (arrival wash).** A substitution request that appears in the teacher's
   list (`SubstitutionCard`, `fresh`) gets `anim-arrive`: a selected-tint wash behind the row starts at
   full strength after 200 ms and fades out over 1.6 s `--ease-out`. The strike line and the state word
   play as in item 4. The schedule's `useArrivedChanges` drops its mark after 1 s, so a remount of the
   same cell does not replay it.
7. **Disclosures reveal.** Content opened by a disclosure (`anim-reveal` on an un-`hidden` panel, or a
   `<details open>` body) drops 4 px and fades in over 200 ms `--ease-out`. The height changes at once:
   no height animation, no per-frame layout.

**Hover delays (`Tooltip.helpers.ts`)**

- Tooltips open after 300 ms (`HOVER_DELAY_MS`); moving straight to the next tooltip within 300 ms
  skips the delay (`skipDelayDuration`).
- `HoverDetails` (the lesson card and other detail cards) opens after 550 ms (`HOVER_CARD_DELAY_MS`)
  and closes 100 ms after the pointer leaves (`HOVER_CARD_CLOSE_DELAY_MS`), so the pointer can cross to
  the card. Right after another card was open it opens at once.
- The delays apply to the mouse only. Enter or a tap toggles the card at once.
- Admin `HoverCard`s (lesson list, order sheet, board chip) set their own: 350–400 ms open,
  100–120 ms close.

**`prefers-reduced-motion: reduce`:**
- All transitions and animations are off.
- Values update in place: the line jumps, the digits swap.
- The mark is shown fully drawn.
- No arrival wash and no reveal: rows and disclosure content appear in place.

## 7. Restraint budget (the "not overloaded" rules, enforceable in review)

| Area | Visible at rest, at most | Moves to a menu, hover or disclosure |
|---|---|---|
| Public header | wordmark, 3 text links (Розклад, Заміни, Дзвінки), search, «Увійти» | theme override (footer), Telegram (footer), «Про систему» (footer) |
| Page header | title, 1 line of context, ≤ 2 controls (День/Тиждень, week stepper), `⋯` | share, ICS, QR, print, subgroup filter → `⋯` |
| Any section or panel | **1 primary** button, ≤ 2 secondary or ghost | everything else → `⋯` |
| List or table row (pointer) | 0 buttons at rest | row actions appear on hover or focus (`RowActions`) |
| List or table row (touch) | 1 trailing `⋯` | — |
| Lesson cell | ≤ 3 text lines plus 1 state line | full name, original lesson, reason, order №, jump links → hover card or sheet |
| Admin option (not top) | title plus 1 reason sentence (plus 1 warning line if any) | «Призначити» appears on hover, focus or selection |

**Numbers.**
- A number appears only when it decides something: a time, a room, a "3 з 7" still to resolve.
- No KPI tile rows.
- Zero counts are never shown: write it in words ("Сьогодні замін немає") or hide the block.
- At most one count per section heading, and always with its noun («2 заміни цього тижня»).
- Scores (`OptionDto.score`) are never shown.

**Letters.**
- Parity and week number appear **once** per screen.
- No help paragraph under every field (§11.4).
- No "A · B · C · D" meta strings longer than 2 separators.
- No feature descriptions under page titles.
- Order and amendment numbers appear only in hover cards and in the order sheet.

**Badges.**
- Lesson states are never chips.
- `Badge` is kept only for admin entity statuses that have no sentence form (import job state). Even
  there, prefer `StatusText` (dot plus word).

**Density per breakpoint.**
- 360–767: one column, one idea per block, no side-by-side metadata.
- 768–1023: two columns on home only.
- ≥ 1024: the full grid and the 3-column admin.
- ≥ 1920: extra width becomes margin, never more columns or more data (§13).

### 8.1 Now-hero with a day track that cannot overlap labels (home)

**Layout at ≥ 768:** a flat `bg-today-wash` block, `rounded-hero`, 32/40 px padding, no border and no shadow.

3. **Optional one line** if a remembered group (`favorites.lastViewed`) has a lesson now:
   «У 4КІ1 зараз Прогр., ауд. 301, Стець» (caption, secondary, with the group code as a link).
4. **Day track:** three stacked rows on one CSS grid with **identical column definitions**:
   - **Pill row (20 px):** only the now pill («12:32», `meta` 600, accent fill and on-accent text,
     `rounded-full`).
     - It is positioned *inside the current pair's column* at `left: clamp(0, x − w/2, colWidth − w)`,
       so it can never leave its column.
     - During a break it sits in the gap column.
   - **Bar row (8 px):** one rounded-full segment per pair.
     - Past: `fill-track-past`.
     - Current: a `bg-selected` track with an accent fill growing to the elapsed fraction.
     - Future: `fill-track-future`.
     - All pairs are equal width. The gaps are 8 px, and a long break (≥ 20 min) gets a 20 px gap.
       That keeps rhythm without a time axis.
   - **Label row (16 px):** **at most two labels**, both start-aligned in their *own* column: the
     current pair («12:10–13:10», accent, `figures`) and the next pair («13:30», muted).
     - A label never spans into a neighbouring column (`min-width: 0; overflow: clip`).
     - No end-aligned labels.

   This makes a collision impossible: one label per column, and columns are at least
   (1216 − 80) / 8 ≈ 140 px at 1440 and at least 80 px at 768.
5. **Accessibility:** the bar is `role="img"` with an `aria-label` from the sentence. The existing
   `liveText` keeps `aria-live="polite"` and changes only on a state change, not every minute.

**States**, each rendering only the headline and the sentence; the track adapts:

|---|---|---|

## 11. Component guidance (`src/components/ui/*`)

### 11.1 Buttons (`Button`, `IconButton`)

| Variant | Look | Rule |
|---|---|---|
| primary | accent fill, on-accent, 40 px, `rounded-control`, `ui` 650 | **One per area** (§7) |
| secondary | surface, `border-default`, primary ink | ≤ 2 visible per area |
| ghost | transparent, accent text, hover `bg-hover` | inline actions («+ Додати відсутність», «Інший викладач…») |
| danger | danger fill, white | **only** inside a confirm dialog |
| icon | 36 px (44 on touch), `rounded-control`, hover `bg-hover` | always has `aria-label` plus a tooltip |

- Press: `scale(0.98)`.
- Loading: the label stays and a 16 px spinner replaces the icon. The button never resizes.

### 11.2 Segmented control and tabs

- **Segmented control:**
  - The track is `bg-sunken` with a 4 px inset, `rounded-control`.
  - The selected segment is `bg-surface` with `shadow-popover`'s ring only, in primary ink.
  - Height 36. **One style everywhere**: День/Тиждень, Сьогодні/Завтра, Уся група/1 п/г. The theme switch is no longer one of them.
- **Tabs (in-page):** text plus a 2 px accent underline, like the header links.

### 11.3 Search and command palette

- **Search field:** a 20 px search icon and the placeholder «Група, викладач або аудиторія».
  - Results are grouped (Групи, Викладачі, Аудиторії) with the match in 700.
  - At most 8 results; on Enter, the top result opens.
- **`CommandPalette` (cmdk):** `bg-raised`, `rounded-dialog`, `shadow-dialog`, 560 px wide, the same
  groups, plus admin commands when signed in.

### 11.4 Forms (`Field`, `Input`, `Select`, `Combobox`, `Textarea`, `Checkbox`, `Switch`)

- Labels go above the field (`caption` 650, primary).
- Help text: **only** when the field is not obvious, one line, caption muted. An error **replaces**
  the help text (cancel text with a 14 px icon) and is linked with `aria-describedby`.
- Fields:
  - 44 px tall, `rounded-control`, `border-control` 1 px;
  - hover `border-strong`;
  - focus: a 2 px `outline-focus` ring with a 2 px offset;
  - placeholder in muted, as an example only.
- Groups of related fields sit in one column with 16 px gaps. Settings dialogs use a 2-column grid
  only at ≥ 1024.
- Sliders in Generation drop their per-slider paragraphs. A single «Що означають ваги?» disclosure
  sits under the group.
- Submit: one primary at the end, left-aligned with the fields, with «Скасувати» as secondary beside it.

### 11.5 Dialogs and sheets (`Dialog`, `ConfirmDialog`, `Drawer`)

- **Dialog:**
  - `bg-raised`, `rounded-dialog`, `shadow-dialog`, scrim behind.
  - Width 480 (confirm) or 640 (form).
  - Padding 24.
  - Title in `title`, with no subtitle unless it states a consequence.
- **Footer:** at most 1 primary and 1 secondary. Destructive confirm: «Видалити» in danger fill and
  «Скасувати»; the dialog's text names the object and says whether it can be undone.
- **< 768:** dialogs become `Drawer` bottom sheets: top radius 20, a grab handle, full width, the
  footer sticky above the safe area.

### 11.6 Toasts (`Toaster`, sonner)

- `bg-raised`, `rounded-popover`, `shadow-popover`.
- One line of `ui` text, an optional 8 px state dot and an optional single action («Скасувати»).
- Position: bottom-right on desktop, bottom-centre above the tab bar on mobile (`toastClearance`
  already handles this).
- Auto-dismiss after 4 s; 8 s if there is an action.
- At most 2 visible.
- No icons apart from the dot, no title plus description pairs.

### 11.7 Tables (`DataTable`)

- Rows 44 px (compact 36 in Accounting and Load).
- Header: `caption` 650, secondary, sentence case, sticky, with a bottom hairline.
- No zebra stripes and no vertical rules.
- Numbers are `figures`, right-aligned. An empty value is «—» in muted.
- One status per row at most, as `StatusText` (dot plus word).
- Row actions:
  - `RowActions` `⋯` appears on hover or focus-within;
  - it is always visible on touch;
  - the primary row action is a click on the row itself.
- **Selection checkboxes** appear only when bulk actions exist. Bulk actions show in a slim bar that
  replaces the table header while something is selected.
- **< 768:** tables become stacked lists: the primary field as the title, two secondary fields as a
  caption line, and the rest in the row's sheet. No horizontal scroll of a squeezed table.

### 11.8 Cards and lists in admin

- No "card grid". A list is rows on the panel surface with hairlines.
- A "card" (`Panel`) exists only to group a whole workspace: one per screen, `rounded-panel`,
  `border-default`, no shadow.
- List row anatomy: title (`cell`), one caption line, optional status word on the right, actions hidden (§7).

### 11.9 Empty, loading and error states (`EmptyState`, `Skeleton`, `ErrorState`)

- **Empty:**
  - One sentence in body, secondary, written for this situation. Examples: «Сьогодні замін немає.»,
    «На четвер ніхто не відсутній.», «Розпорядження на сьогодні ще не створене.»
  - Plus at most one ghost action.
  - No box, no dashed border, no illustration, no giant watermark. The empty order draft is a
    sentence, not an empty A4 sheet.
- **Human endings** are the "alive" copy: «На сьогодні все. Завтра перша — о 09:40, ЕУ, ауд. 22.»
- **Loading:** static skeletons shaped like the real content in `bg-skeleton`, with no shimmer loop.
  They appear after 300 ms (to avoid a flash) and then fade in over 160 ms.
- **Error:** one sentence about what happened and what to do, with «Спробувати ще раз» as secondary.
  Offline is a calm line in the page header, «Немає звʼязку — показуємо збережений розклад», not a banner.
- **404:** «Такої сторінки немає.» (`headline`) plus search and «На головну» (ghost). No giant «404».

### 11.10 Copy

- Plain Ukrainian, sentence case, short.
- Times as «08:30», dates as «Середа, 11 листопада».
- «4 пара» in the hero and headings; `pairOrdinalLabel` («5-та пара») inside sentences.
- Remove the tram and route vocabulary from the UI: «зупинка», «Маршрут ранку», «обʼїзд»,
  «Нічого не горить».
- No instructions about keys in the UI. Shortcuts live in `ShortcutsDialog` (opened with `?`).

## 12. Dark theme specifics

- **Layering by lightness:** sunken 16 % < canvas 17.8 % < surface 21 % < raised 24 % < hover 25.5 %.
  A higher layer is always lighter. No pure black (`#000`) and no pure white text (95.5 % ink).
- **Washes stay low-chroma** (C ≤ 0.035, L 24.5–25.5 %) so amber never turns to brown mud. The state
  **text** carries the colour (83 % amber), not the fill. Check «Заміна» cells in the today column,
  where the change wash wins over the today wash.
- **Accent flips lighter** (77 % text, 74 % fill) with dark on-accent text (20 %). White on a mid
  blue fails AA, so do not use it.
- **Shadows** become a 1 px white/8 % ring plus a deep soft shadow. Hairlines are 27.5 % and 32 %.
- **Discipline dots** go up to 72 % lightness and drop chroma to 0.09, so they glow less.
- **Islands** (`data-theme="light"`): the order sheet, `QrPlate`, `SchedulePrint`, `OrderPreview`,
  the signature preview in `SettingsForm`, and the `DisciplineColorField` previews. They stay light
  once §3.1 is applied, and they need a 1 px `border-default` from the *dark* context around them.
- **Theme switch:** keep the inline script in `index.html` (no flash) and the View Transition, but
  change the transition from "жалюзі табло" to a plain 200 ms cross-fade, and update the comment.
  `meta theme-color`: `#f8fafd` / `#0e1116`.
- **Screenshot check** before merge: home, group week and admin changes in both themes at 1440, plus
  home at 390 in both themes (full-page, emulated `prefers-color-scheme`, reduced motion).

## 14. Do and don't

**Do:**
- Lead each screen with one human answer: «4 пара · 38 хв до дзвінка», «4КІ1», «Вирішено 3 з 7 пар».
- Keep time labels in their own column or row, one per column, start-aligned.
- Show a change as a word, a strike-through of the old value and a wash. Make sure it reads in greyscale.
- Put secondary actions behind `⋯`, hover/focus or a disclosure, and keep one primary per area.
- Use Geologica `figures` for every column of times and numbers.
- Fade finished pairs today, and say what is next in a sentence.
- Use hairlines and tone steps for structure; use shadows only for floating layers.
- Follow the system theme, and test every screen in both themes and at 360 and 1440.
- Keep the slop-check passing. Update its messages and comments from "трамвайний" to this
  direction, and keep the `backdrop-blur` and gradient bans.

**Don't:**
- Use the navy header band, condensed type, route plates, departure-board rows or the tram vocabulary.
- Use the college site's look: full-bleed blue bars, grey backdrop, Arial 13, dense dropdowns, justified text.
- Use proportional time axes with labels positioned by minute. That is where 08:30/09:40 collided.
- Use chips or badges for lesson states, rank numbers, scores, uppercase labels, or counts without a noun.
- Show KPI tile rows, `0` counts or the same parity more than once per screen.
- Use discipline colour as a fill, as text colour or as a side bar on a rounded card.
- Use more than one filled button in an area, or icon-only buttons without a label or tooltip.
- Use looping decorative motion, shimmer skeletons, parallax, glassmorphism, gradients, glows or emoji.
- Use `light-dark()` in semantic tokens (§3.1).
- Use Unbounded or any face where «4КІ1» can read as «4КП».

## 15. In the code

**Tokens** live in `src/styles/theme.css`:

- Raw values `--c-*` are declared once per theme: `:root, [data-theme='light']` and `[data-theme='dark']`.
- Role variables (`--background-color-surface`, `--border-color-separator` and the rest) are re-declared on
  every `[data-theme]` element as `var(--c-*)`, so `var(--role)` in an arbitrary value resolves on the island
  itself. `@theme inline` points the utilities (`bg-surface`) at the same `--c-*` values.
- Keep the three colour blocks in the same role order. Add a role to all three or to none.
- Retired roles stay as aliases until their last usage is gone: `shell*`, `on-shell*`, `plate`,
  `border-shell`, `focus-on-shell` (canvas, ink, separator, focus), `rounded-plate` (= `rounded-tag`) and
  `font-condensed` (= Geologica). New code does not use them.
- `.figures` sets Geologica with tabular figures. `text-title`, `text-headline`, `text-display` and
  `text-numeral` get Geologica automatically (`@layer components` in `base.css`); `font-sans` next to them
  wins.

**Components other areas build on** (all from `@/components/ui` unless noted):

| Need | Use |
|---|---|
| Page title, a way back, ≤ 2 controls, one primary action, `⋯` | `PageHeader` (`title`, `meta`, `controls`, `primaryAction`, `more`, `back`, `size`). The back link comes from `parent` in `src/app/routes.ts`; admin pages hide it at ≥ 1024 px, where the sidebar is always visible. |
| A back link outside `PageHeader` | `BackLink` (`to`, `label`) or `useBackLink()` from `@/hooks/useBackLink` |
| Secondary actions | `MoreMenu` (`items: { label, icon?, onSelect? / to? / href?, tone?, separatorBefore? }[]`) |
| One error for the whole page | `PageErrorScope queries={[a, b, c]}` around the page body: one `PageErrorBanner` with one «Спробувати ще раз» that refetches every failed query; `ErrorState` inside becomes a quiet line. `PageErrorBanner` alone for a single query. |
| Empty and error blocks inside a bordered card | `EmptyState inset` / `ErrorState inset` (16 px side padding) |
| Tables | `DataTable` stacks into a list below 768 px (`stackOnMobile`, default on). Give non-string headers a `mobileLabel`. |
| Now and the day | `NowIndicator variant="hero"` (home), `"strip"` (Дзвінки), `"compact"` (phone above the day list), `"inline"`; `DayTrack` for a custom layout. All from `@/components/schedule`. |
| Theme choice | `ThemeMenu` (footer), `ThemeRadioItems` (inside any Radix menu) from `@/components/shell/ThemeToggle` |
| The mark | `BrandMark` (`size`, `draw` for the sign-in screen) from `@/components/shell/Wordmark` |
| Undo instead of confirm | `notify.undo(message, { onUndo })` — 8 s with «Скасувати» |

**Routes.** `parent` (route id) on every page that is not the top of its section; `nav.section` is
`'Щодня' | 'Планування'`; `nav.sidebar: false` hides a page from the sidebar but keeps it in the palette;
`nav.sidebarLabel` and `nav.activePrefix` merge the five catalog pages into one «Довідники» item.
